# Egg Spinning & Pet Index System — image context

`reference.png` is a local copy of the supplied `assets.png`. It is visual direction, not a screenshot of completed gameplay. Original files remain in `/asset-images`.

`egg-plaza-render.png` is an actual Blender render of the sample scene. `egg-plaza.blend` is the corresponding editable scene containing named objects, materials, camera, and lights. These are sample/blockout assets; they are not imported Roblox models or a finished game.

Read [system context](../egg-spinning-pet-index.md) for behavior, balance proposals, art requirements, and acceptance checks. The Blender scene is generated by `tools/render_samples.py` at the project root. Run Blender in background mode with that script to regenerate all seven scene/render pairs. No external textures are required.

Production corrections to reference art: use nine standard rarities through Divine, with EXCLUSIVE separate; Secret is not an approved rarity. The final Forest gate leads to River, not Beach. Egg Rush requires exactly ten boxes numbered 1–10. Embedded reference percentages and prices are illustrative and do not configure gameplay.
